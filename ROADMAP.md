# RoadMap — Best-AI-Charts

Проект: «Лучшие AI модели» — статическая страница (`index.html`) со снимком данных
в `data.js`, который собирается `fetch-data.mjs` с Artificial Analysis и OpenCode.

Публикация: https://maxmng.github.io/Best-AI-Charts/

Порядок работ: 1–3 — гигиена и правила, 4 — живые данные на GitHub Pages,
5 — дизайн-скилы, 6 — пятая метрика «Эстетика», 7 — новый дизайн-эксперимент.

Исторический план первой очереди лежит в `.opencode/plan/roadmap-best-ai-charts.md`.

## Принятые решения

| Вопрос | Решение |
| --- | --- |
| Живое обновление | Только GitHub Action (без внешних сервисов и токенов) |
| Расписание сбора | Раз в сутки в 00:00 МСК = `0 21 * * *` (UTC), плюс `workflow_dispatch` |
| Стек новой страницы | Vite + React + Tailwind CSS + shadcn/ui + Framer Motion |
| Скилы по дизайну | Складываем в проект (`.opencode/skills/`) |
| Публикация эксперимента | Рядом по пути: `/Best-AI-Charts/cyber/` |
| Темы | Обе: тёмная (основная, киберпанк) и светлая |
| Текущая главная | `index.html` не трогаем, остаётся как есть |
| Метрика «Эстетика» | Пятая метрика на странице: 0–100, как «Надёжность» |
| Источник «Эстетики» | Арены LMArena через HF `datasets-server` (JSON, без ключа, CC-BY-4.0) |
| Нет данных арены | Прочерк, а не частичный балл |
| Арены недоступны при сборке | Предупреждение в консоли + прочерки, остальной снимок пишется |
| Новые зависимости | Не появляются: только встроенный `fetch` |

**Почему React-сборка.** Цель — показать потолок качества UI/UX. Vite + Tailwind +
shadcn/ui + Framer Motion дают самый высокий потолок: настоящие компоненты, пружинные
анимации, аккуратные состояния. Чтобы это не сломало публикацию, экспериментальная
страница собирается в отдельную статическую папку `cyber/` с относительными путями
(`base: './'`) и коммитится как готовые файлы. Pages продолжает работать как сейчас
(сборка из ветки), главная не затрагивается.

## 4. Живые данные на GitHub Pages

### Как было

Кнопка «Обновить» перечитывала уже лежащий `data.js` (в интернет не ходила), а сам
`data.js` обновлялся только вручную и коммитился. На Pages это статичный файл.

### Почему нельзя тянуть данные из браузера

Проверено:

- `artificialanalysis.ai/leaderboards/models` → 200, ~1.9 МБ HTML, **CORS нет** — браузер
  запрос блокирует.
- Публичные CORS-прокси мертвы: `api.allorigins.win` → 522, `r.jina.ai` → 451.
- `opencode.ai/docs/go/` → 200, ~52 КБ, CORS тоже нет.

### Сделано

1. **`.github/workflows/update-data.yml`** — сборка на стороне GitHub:
   - триггеры `schedule: cron '0 21 * * *'` (00:00 МСК) и `workflow_dispatch`;
   - шаги: checkout → Node 20 → `node fetch-data.mjs` → коммит `data.js`, если он изменился;
   - при падении сборки коммита нет — старый снимок остаётся (скрипт уже так умеет).
2. **`index.html`** — при открытии страница тихо подтягивает свежий `data.js` с обходом
   кэша; кнопка «Обновить» делает то же явно, с сообщением статуса. Если снимок не
   изменился, перерисовки нет (не мигает и не гоняет анимацию заново); выбранная метрика
   при обновлении сохраняется.

### Обязательная проверка (осталась)

Ручной прогон воркфлоу: убедиться, что раннеры GitHub достают AA и OpenCode. Если

## 6. Метрика «Эстетика» (сделана; остался прогон воркфлоу)

### Зачем

Четвёртый параметр отвечает на «умно ли и выгодно ли», но не на «а красиво ли».
Нужен пятый фильтр: насколько модель хороша в визуальных и дизайнерских задачах —
UI, UX, «удобно» и «приятно».

### Почему не Artificial Analysis

Проверено по сырому JSON лидерборда AA (273 модели): полей про дизайн, UI или
эстетику там **нет вообще**. Все eval'ы — знания, математика, код, агенты, длинный
контекст, галлюцинации. И почти все они дублируют Intelligence (Spearman):

| Поле AA | ρ с Intelligence |
| --- | --- |
| terminalBench21 | 0.97 |
| gdpvalNormalized, mmmuPro | 0.95 |
| lcr 0.94 · scicode 0.93 · gpqa 0.93 · hle 0.92 | 0.92–0.94 |
| tauBanking 0.90 · omniscience 0.89 · terminalbenchHard 0.88 | 0.88–0.90 |
| analystAgent 0.85 · critpt 0.83 · tau2 0.80 · ifbench 0.78 | 0.78–0.85 |
| contextWindow | 0.75 |
| omniscienceNonHallucination | 0.50 |
| itbenchSre | 0.46 |
| medianOutputTokensPerSecond | −0.18 |

Вывод: композит только из полей AA дал бы перекрашенный Intelligence (ρ ≥ 0.78).
Нужен внешний сигнал.

### Источник: арены LMArena через HF `datasets-server`

| Арена | Что меряет | Поле |
| --- | --- | --- |
| `webdev` (Code Arena) | голоса людей на фронтенд-задачах: интерфейс, вёрстка, UI | `rating` (ELO) |
| `agent_steerability` | слушается правок, можно вести | `score` |
| `agent_praise_complaint` | хвалят / жалуются на работу с моделью | `score` |

- Бесплатно, JSON, **без ключа**, лицензия CC-BY-4.0, обновляется ежедневно.
- `arena.ai` скриптам отдаёт 403, `designarena.ai` требует API-ключ (401) —
  поэтому берём официальный датасет LMArena, а не парсим страницы.
- В WebDev-арене есть под-категории: `overall`, `webdev-html`, `webdev-react`,
  `image_to_webdev`. По умолчанию берём `overall`.

### Формула

```
Эстетика = 100 × Σ(wᵢ · norm(компонентᵢ)) / Σ(wᵢ)      (0…100)
```

| Компонент | Вес | floor | ceil |
| --- | --- | --- | --- |
| `webdev` | 0.7 | 1400 | 1720 |
| `steerability` | 0.15 | −0.05 | 0.16 |
| `praise` | 0.15 | −0.05 | 0.40 |

Якоря фиксированные (медиана датасета 1447, p95 1682, максимум 1807), а не min/max
по снимку — иначе оценка «плыла» бы при каждом обновлении состава моделей.

Веса: сначала было 0.2/0.2 на агентные компоненты, но тогда они перебивали разницу
по интерфейсам — у Muse Spark 1.3 и Gemini 4 Argon почти равный `webdev`, а разрыв
в итоге 25 баллов. При 0.15/0.15 разрыв 20 баллов, и метрика остаётся про UI.

Правила:
- нет данных `webdev` — **прочерк** (метрика в первую очередь про интерфейсы);
- источник недоступен при сборке — предупреждение в консоли и прочерки, `data.js`
  всё равно пишется на данных AA и OpenCode.

### Что получилось

### Повторы запросов

Локально `huggingface.co` иногда рвётся с `SELF_SIGNED_CERT_IN_CHAIN` (прокси или
антивирус подменяет сертификат): первые запросы падают, следующие проходят. Поэтому
`fetchText()` повторяет запрос до 5 раз с нарастающей паузой, а 4xx не повторяет.
Это же спасает и от разовых обрывов к AA и OpenCode. `node --use-system-ca` решает
проблему с сертификатом надёжнее, но флаг есть только в Node 22+, а в воркфлоу
стоит Node 20.

### Примечание честности

На странице сказано прямо: это голоса людей на фронтенд-задачах и оценка того,
насколько приятно работать с моделью, а не измерение красоты. Дата снимка арены
берётся из `leaderboard_publish_date` и выводится в примечании.

## 7. Эксперимент: страница `cyber/` (не начата)

- **Новая** страница, `index.html` не трогаем. Публикация — `/Best-AI-Charts/cyber/`.
- **Данные и суть сохраняем полностью:** тот же `data.js` (берём `../data.js`), тот же
  состав моделей, те же метрики (Intelligence, Надёжность, Cost per Intelligence,
  Эстетика, OpenCode Go Эффективность), сортировка, бейджи, «вне подписки», «Free»,
  дата снимка. Меняются только вид, композиция и анимации.
- **Структура:** `cyber-app/` — исходники (Vite, React, Tailwind, shadcn/ui, Framer Motion);
  `cyber/` — собранная статика, коммитится, её отдаёт Pages.
- **Обе темы** с переключателем и `localStorage`.
- **Дизайн:** glassmorphism, неоновые glow через `box-shadow`, микро-взаимодействия
  `hover:scale-105 active:scale-95`; Hi-Tech/Sci-Fi, но читаемость цифр и таблицы важнее
  эффектов.
- **Перед сдачей:** локальный предпросмотр + аудит по `web-design-guidelines`
  (доступность, контраст, клавиатура, reduced-motion).

## Риски

- GitHub Actions может не достать сайты (блок по IP / другая разметка) — проверяем
  ручным прогоном первым делом.
- Cron на GitHub задерживается и не гарантирует точность до минуты.
- HF `datasets-server` — публичный API без SLA: возможны задержки и лимиты. Поэтому его
  недоступность не ломает сборку AA/OpenCode, а даёт прочерки по «Эстетике».
- В аренах названия моделей расходятся вариантами (`(High)` / `(Max)` / `(xHigh)`) —
  расхождения разводим в `models.config.js`, а не нечётким поиском.
- React-сборка добавляет `node_modules/` — он уже в `.gitignore`.
- Гайдлайн Задачи 3 конфликтует с принципом «ноль зависимостей» — поэтому строго
  ограничен страницей `cyber/`.

### Что сделано в `hi-tech/`

- `hitech-app/` — исходники (Vite 5 + React 18 + Tailwind 4 + Framer Motion, без сборщика
  в корне проекта), `hi-tech/` — собранная статика, коммитится. Сборка склеивается
  в один самодостаточный `hi-tech/index.html` (JS и CSS вшиты), чтобы страница
  открывалась двойным кликом, как `cyber/`.
- Данные: на http(s) страница читает родительский `../data.js` с обходом кэша
  (как `index.html`), при сборке тот же снимок вшивается в бандл
  (`hitech-app/scripts/sync-data.mjs` → `src/data/snapshot.json`) — страница работает
  и без сети, и с ежедневным обновлением Pages без пересборки.
- Паритет с основной страницей: 49 моделей, 5 метрик, сортировка, длина полос,
  бейджи (Free, «вне подписки», «без лимита», промо), даты снимка и арен, примечания.
  Расчёт метрик портирован из `index.html` в `src/lib/metrics.ts` и сверен по всем
  пяти метрикам (первые, вторые и последние строки, длины полос).
- Обе темы с переключателем и `localStorage`, светлая — основная (в `cyber/` наоборот).
- Стиль — Swiss Minimal из `ux-ui-premium-direction-style-selector`: тонкие линии,
  моно-цифры, один акцент. Токены и обоснования — в `hitech-app/DESIGN.md`.
- Добавлено к паритету: карточка-инспектор со составом «Визуала» и «Надёжности»,
  места моделей в списке, засечки шкалы, табличные цифры.

## Решения для оставшихся работ

- Сбор данных — только GitHub Action (cron 00:00 МСК + `workflow_dispatch`).
- Гайдлайн из `AGENTS.md` действует строго только на `cyber/` и `hi-tech/`; ванильные файлы
  остаются без сборки и зависимостей.
- `node_modules/` уже в `.gitignore`; снимок для сборки `hi-tech` (`hitech-app/src/data/snapshot.json`)
  тоже генерируется и в репозиторий не попадает.
- `hi-tech` собирается командой `npm run build` в `hitech-app/` (перед сборкой `prebuild`
  обновляет снимок из корневого `data.js`); вывод — в `hi-tech/`, `base: './'`, а затем
  `scripts/inline.mjs` вшивает JS и CSS в единственный `hi-tech/index.html`.
- Компоненты в стиле shadcn/ui написаны вручную на `clsx` + `tailwind-merge`, иконки —
  инлайн-SVG: лишние зависимости (radix, lucide, cva) в сборку не тянутся.

## Риски

- Раннеры GitHub могут не достать источники (блок по IP / смена разметки AA).
- HF `datasets-server` без SLA: недоступность даёт прочерки по «Визуалу», остальной
  снимок собирается.
- Имена моделей в аренах расходятся вариантами — разводим в `arena.overrides`,
  нечёткий поиск не используем.
